ROADMAP

Implementation roadmap

A phased rollout model reduces risk, validates the platform through a pilot plant, and scales the solution globally through controlled deployment waves.

Design
Strategic Design

Define the operating model

After management validation, the team designs the academy organization, learning structure and KPIs.

Initial phase
Build
Operational Construction

Build the first platform version

During 2026, the first version of the platform is developed with external support, while internal content such as Kairoslingo is created internally.

2026
Pilot
Pilot Validation

Test scalability and stability

A pilot plant in Poland is used to validate the solution, test scalability and capture lessons learned before broader deployment.

Pilot plant
Deploy
Deployment Waves

Scale across divisions

Deployment runs during 2027 and 2028. Europe and Asia start first, followed by NAFTA, Mercosur and Edscha.

2027–2028
Scale
Massive Deployment

Optimize and include all plants

After the first waves, the process expands to all plants and is continuously optimized using feedback, adoption data and operational results.

Global scale
