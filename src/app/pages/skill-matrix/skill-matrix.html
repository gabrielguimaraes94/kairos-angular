1

Roles — WHO

Defines expectations by role, not by individual.

  • Operator • Technician • Engineer • Manager
  • Standard comparison across plants and regions
  • Clear expectations for each responsibility level
2

Skill Levels

Defines target maturity by role and technology area.

  • Beginner — common language
  • Intermediate — practical autonomy
  • Advanced / Expert — lead execution
  • Certified — reference and multiplier
3

Training Strategy

Beyond e-learning: apply, validate and sustain.

  • Platform modules and internal champions
  • External training when specific expertise is required
  • Practical projects using learning by doing
4

Learning Paths Connection

Every target skill connects to a structured learning path.

  • Paths define modules, hands-on practice and validations
  • Each path supports different roles and maturity levels
  • Progression can evolve into certification and local trainers
